# MediCare Hospital Website 🏥

## 📌 About the Project
MediCare Hospital Website is a responsive, multi-page hospital website developed using HTML5 and CSS3. It provides essential information about the hospital, its medical departments, doctors, and contact details through a clean and user-friendly interface.

## ✨ Features
- Home page with hospital introduction
- About Us page
- Medical departments section
- Doctors' profiles
- Contact and appointment enquiry form design
- Responsive layout for different screen sizes
- Simple and professional healthcare-themed design

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Navigate through the pages using the navigation menu.

## 🎯 Project Objective
The objective of this project is to practice HTML and CSS by building a structured, multi-page hospital website with a professional design.

## ⚠️ Note
This is a front-end demonstration project. The appointment enquiry form does not submit or store data unless backend functionality is added.
